Credits

This website is generated using Jekyll and built with Leaflet (v1.9.4), normalize.css (v8.0.1) by Nicolas Gallagher, npm, and webpack with css-loader and mini-css-extract-plugin. Type is set in Archivo, Public Sans, and IBM Plex Mono, served by Google Fonts. Map tiles are provided by OpenStreetMap and OpenTopoMap, whose map style is licensed CC BY-SA and whose relief is derived from SRTM elevation data. The publication list is generated with jekyll-scholar.
